# interactor-test-fbx-sketchfab-03

Community 3D models grouped by author, each with a record of its source and licence, as fixtures for an FBX importer test.

## What it is for

The files are fixtures for an importer test kept elsewhere; this repository holds no test. Most models are an FBX file with reference OBJ geometry beside it, including a posed frame for some animated models, but not every model carries both. A JSON record per model gives its title, author, source and licence.

## Build and run

There is nothing to build; the files are read as they are.

## Licence

Each model's licence is in its JSON record. The repository adds none of its own.
