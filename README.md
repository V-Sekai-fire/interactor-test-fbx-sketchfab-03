# interactor-test-fbx-sketchfab-03

Community FBX models grouped by author, each with reference OBJ geometry and a record of its source and licence, for import tests.

## What it is for

An importer test reads each FBX file and compares what it gets with the OBJ beside it, including a posed frame for some animated models. A JSON record per model gives its title, author, source and licence.

## Build and run

There is nothing to build; the files are read as they are.

## Licence

Each model's licence is in its JSON record. The repository adds none of its own.
